# **App Name**: ArabDevs

## Core Features:

- Secure User Authentication & Profiles: Enables user registration, login, password recovery, and management of individual student and admin profiles, storing necessary details like name, courses, and progress.
- Interactive Course & Lesson Player: Allows students to view course content, including video lessons with playback controls (play, pause, speed), accompanying textual summaries, and additional downloadable files. Automatically tracks lesson completion and overall course progress.
- Certification System & Verification Tool: Issues official digital certificates for completed courses, featuring student name, course name, issue date, a unique certificate number (e.g., CERT-2026-000845), and a verifiable QR code. Includes a public page for certificate validation.
- Admin Content & User Management: Provides administrators with a comprehensive dashboard to manage courses, videos, books, tests, certificates, user accounts, and review manual payment slips for course activation.
- Progressive Quizzing & Assessment: Offers various types of interactive quizzes, including multiple choice and true/false, at the end of lessons or modules to evaluate student understanding and provide immediate feedback with results.
- AI-Powered Study Tool: An integrated generative AI tool that can assist students by answering questions related to the current course material or generating additional practice questions based on the lesson content.
- Community Discussions & Interactions: Enables students to post comments and ask questions directly within course lessons, fostering interaction and community learning among peers and instructors.

## Style Guidelines:

- Primary color: A rich, professional purple (#622695) inspired by digital creativity and wisdom. This hue offers depth and sophistication.
- Background color: A subtly tinted light gray (#F0EDF3) with a hint of purple, ensuring readability and a modern, clean canvas while staying true to the primary color's hue.
- Accent color: A vibrant, clear blue (#3359F2), analogous to the primary purple, selected to draw attention to interactive elements like buttons and highlight key actions, fulfilling the request for 'blue for buttons'.
- Headline font: 'Space Grotesk' (sans-serif), for a modern, tech-savvy, and clean look that captures the spirit of programming education.
- Body and UI font: 'Inter' (sans-serif), chosen for its exceptional readability across various screen sizes and its modern, neutral aesthetic, ensuring clear communication of all course content and interface elements.
- Code font: 'Source Code Pro' (monospace sans-serif), specifically for displaying code snippets with optimal clarity and standard developer aesthetics.
- Use a set of clear, minimalist line icons that are easily recognizable and support the intuitive navigation and function of the platform. Prioritize icons that convey educational, technical, and interactive concepts.
- Implement a minimal and modern layout with generous whitespace to ensure ease of use and prevent visual clutter, prioritizing content display as per the user's emphasis on rapid access and comprehension.
- Incorporate subtle and lightweight animations for transitions and interactive feedback (e.g., button hovers, form submissions, progress updates) to enhance user experience without causing distraction, aligning with the request for 'light animations'.
